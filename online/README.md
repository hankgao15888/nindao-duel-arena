# 忍道决斗场 · 联机部署包

[下载 Radmin 完整联机包](./忍道决斗场-Radmin联机包.zip)（约 9.1 MiB）

压缩包内包含完整网页源码、24 位忍者素材、联机服务器源码、WebSocket 依赖、数据库迁移、Windows 启动脚本、Docker/Caddy 配置和详细中文部署说明。没有附带运行数据库、玩家账号、聊天记录或部署密钥。

## Radmin VPN 好友联机

1. 双方 Windows 电脑打开 Radmin VPN，创建或加入同一个私有网络。
2. 房主下载上面的 Radmin 联机包，完整解压，双击“启动Radmin联机.bat”；保持窗口与 VPN 开启。
3. 打开 [原游戏网址](https://hankgao15888.github.io/nindao-duel-arena/)，点击“联机对战”，输入房主窗口显示的地址，也可直接打开窗口显示的网址。
4. 进入后各自登录或注册，一人创建房间，一人输入房间码，双方准备后开战。

房主电脑承担服务器职责，无需为好友切磋另买云服务器；好友只需 VPN 和浏览器。启动器自动识别 VPN IPv4 地址，并且仅监听该地址。它不会自动修改防火墙或路由器。若连接被拦截，请检查 VPN 连接和 TCP 3000 放行情况。

房主关机或关闭程序后好友无法连接。实际国内网络可达性和延迟仍需双方实测。说明与启动器包含在 Radmin 包内，旧部署包保留供参考。

## 本机启动

1. 下载并完整解压压缩包，进入其中的“忍道决斗场-联机版”文件夹。
2. 安装 Node.js 24 LTS，Windows 双击“启动联机.bat”，保持窗口开启。
3. 打开 `http://127.0.0.1:3000`，首次使用注册自己的账号。
4. 登录后点击“远程联机”，一人创建房间，另一人输入 6 位房间码加入；双方选好三位忍者并准备后开战。

测试两名玩家时可使用两个标签页、两个账号。单机和练习仍可使用。

## 联机功能

- 双人 3V3，双方由真人控制，服务器统一判定伤害、回合和胜负。
- 同步血量、忍术冷却、替身、秘卷、通灵和忍者专属机制。
- 房间码邀请、准备倒计时、延迟显示和双方再次准备再战。
- 15 秒断线重连，刷新页面可恢复同一场对局；超时判负，主动离开认输。
- 独立账号、登录后图片聊天和在线人数，网页与接口使用同一个服务器地址。

## 公开部署

**上传 GitHub 保存的是程序，不表示联机服务已经上线。GitHub Pages 只提供静态网页，不能运行本包的 Node.js/WebSocket 服务。**

异地好友游玩需要将解压后的完整程序部署到双方都能访问的服务器。若希望中国大陆网络直接进入，应选择可在国内访问的部署节点，并在部署后实测线路和延迟。公网使用 HTTPS/WSS；包内提供 Docker Compose + Caddy 示例，详见压缩包内 `README.md`。

`127.0.0.1` 仅指访问者自己的电脑，不能作为发给异地好友的网址。当前没有配套公网服务器或域名，也没有进行中国大陆运营商线路测试。新服务器使用独立数据库，需要重新注册，原网站账号不会自动迁移。

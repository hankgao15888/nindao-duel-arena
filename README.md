# 忍道决斗场

浏览器单机同人决斗游戏，练习对战和三人顺序决斗。使用 HTML、CSS 和 Canvas

## 运行与部署

直接打开 `index.html` 可在本地游玩。

部署到 GitHub Pages 时，上传本目录中的全部文件和 `assets/` 文件夹，保持目录结构；在仓库的 Settings → Pages 中选择 Deploy from a branch、main 分支和 /(root)，保存后等待部署完成。不要只把 ZIP 压缩包作为仓库文件上传。

GitHub Pages 的实际网址以仓库 Pages 页面显示的结果为准，通常采用“用户名.github.io/仓库名/”的形式。此导出目录不包含原 Sites 平台的身份配置、Git 历史或上传凭据。

## 操作

- 每个小回合分出胜负后，双方技能冷却归零；下一位忍者登场时再次重置，包括忍术、替身、秘卷、通灵和专属冷却。
- WASD：移动；J：普攻；U / I：忍术；O：奥义。
- 空格：替身；L：秘卷；H：通灵。
- 忍战带土：U 木遁后再按 U 追加火遁；I 神威后解锁 Q / E 子技能，支持短按和长按。
- 页面也提供触摸摇杆和技能按钮。
- 点击“按键设置”可自定义移动、普攻、技能、替身、秘卷、通灵与带土子技能；初始按键保持上述默认值。修改自动保存到当前浏览器，可随时恢复默认。重复按键自动交换，Esc 保留用于暂停和取消录入。

## 后续更新

`roster.js` 保存忍者资料，`engine.js` 与专属忍者模块处理战斗逻辑，`renderer.js` 与渲染模块绘制角色和特效。修改后将更新文件提交到同一仓库，Pages 会重新部署，网址保持不变。

本项目为非官方同人演示，数值和特效是自制实现。

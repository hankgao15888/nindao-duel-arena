# 忍道决斗场

浏览器单机同人决斗游戏，包含 24 位忍者、练习对战和三人顺序决斗。使用 HTML、CSS 和 Canvas，无需安装依赖或运行服务器。

## 好友联机

选人页面点击“联机对战”，填写房主 Radmin VPN 地址即可进入真人 3V3 对战服务。双方须在同一个 Radmin VPN 网络；房主从 [online 目录](./online/) 下载 Radmin 联机包，解压后双击“启动Radmin联机.bat”，将窗口显示的地址发给好友。

联机游戏提供房间码、双方准备、服务器判定、15 秒断线重连与再战。进入房主服务后使用该服务器的独立账号登录或注册；原网页账号不会自动迁移。GitHub Pages 提供联机入口，实际游戏由房主电脑运行，房主关机或关闭程序后无法连接。此方案主要面向 Windows 电脑，国内异地线路的效果需双方实测。普通单机与练习模式仍直接在原网址运行。

## 运行与部署

直接打开 `index.html` 可在本地游玩。

部署到 GitHub Pages 时，上传本目录中的全部文件和 `assets/` 文件夹，保持目录结构；在仓库的 Settings → Pages 中选择 Deploy from a branch、main 分支和 /(root)，保存后等待部署完成。不要只把 ZIP 压缩包作为仓库文件上传。

GitHub Pages 的实际网址以仓库 Pages 页面显示的结果为准，通常采用“用户名.github.io/仓库名/”的形式。此导出目录不包含原 Sites 平台的身份配置、Git 历史或上传凭据。

注意：联机对决目前处于维护阶段，请谅解，我们团队会想办法解决问题，谢谢！

## 操作

- 每个小回合分出胜负后，双方技能冷却归零；下一位忍者登场时再次重置，包括忍术、替身、秘卷、通灵和专属冷却。
- WASD：移动；J：普攻；U / I：忍术；O：奥义。
- 空格：替身；L：秘卷；H：通灵。
- 忍战带土：U 木遁后再按 U 追加火遁；I 神威后解锁 Q / E 子技能，支持短按和长按。
- 佐助「侠隐江湖」：U / I 消耗剑意，快接 J / O 派生；O→J 消耗一点强化双剑，四点长按 O 发动奥义。炎剑架势和飞鸟中长按 O 分别发动劫火烙八荒和雷麟碎空闪，普通长按 O 发动踏日裁岳。触屏可从技能滑向普攻或奥义。
- 摇杆左右转向，松开保持朝向，普攻与技能沿所选方向释放。技能动作期间提前按 J 可在结束后接普攻；技能命中的短暂浮空便于追击，红保、替身和起身规则继续生效。
- 佐助普攻增加分段位移，强化普攻各段支持摇杆跨 Y；炎刀、天照刀光采用紫色，燎原十八拍与三种奥义增加须佐、刀光、雷麟、裂地和碎石特效。
- 页面也提供触摸摇杆和技能按钮。
- 点击“按键设置”可自定义移动、普攻、技能、替身、秘卷、通灵与带土子技能；初始按键保持上述默认值。修改自动保存到当前浏览器，可随时恢复默认。重复按键自动交换，Esc 保留用于暂停和取消录入。

## 登录与游客权限

本站提供独立的用户名、密码注册和登录，注册后自动登录。用户名为 2—20 个字母、数字或下划线（支持中文），密码为 12—128 个字符。默认仅当前页面会话保持登录；勾选“保持登录”后可在该浏览器保留 7 天。账号不使用 ChatGPT 或原版游戏账号。

游客可使用现有另外 22 位忍者。宇智波带土和后续新增忍者需要登录；新增资料默认需要登录，游客名单在 `auth.js` 中维护。保存阵容、随机阵容、开始对战及退出登录都会检查权限。角色权限属于浏览器游戏界面限制，静态游戏代码无法防止自行修改本地代码。

聊天历史、发言、图片查看和上传、撤回和举报均由服务器验证登录。密码仅以独立随机盐的 scrypt 哈希保存；登录令牌仅以哈希保存在服务器，退出会撤销当前会话。旧的匿名聊天身份不再拥有访问权限。未提供邮箱或密码找回，请记好自行设置的密码。

## 玩家聊天

点击右下角“玩家聊天”可与其他玩家交流，支持昵称、文字、选择或粘贴图片、图片放大、撤回自己的消息和举报。图片会在浏览器压缩后上传。

游戏由 GitHub Pages 提供；共享聊天通过现有 Sites 服务的 D1 数据库和 R2 图片存储运行。聊天内容对登录玩家可见，最多保留 7 天、500 条，窗口显示最近 80 条。聊天记录不保存在 GitHub 文件中。使用同一账号登录后，可以撤回该账号发送的消息。

在线版提供公共聊天；本地离线版仍可游玩决斗场。打开聊天会暂停当前单机对战。

## 在线人数

页面顶部显示共享服务统计的在线浏览器数，约每 25 秒更新。打开游戏即计入；同一浏览器的多个页面合并计一人。正常关闭页面会发送离开通知，断网或异常退出约 90 秒后自动移除。手机横屏和全屏时在游戏画面顶部显示。

统计依赖联网；服务不可用时显示“—”。不同浏览器、设备、无痕窗口或禁止本地存储的页面可能计为不同访客，人数并不表示正在联机对战。

## 后续更新

`roster.js` 保存忍者资料，`engine.js` 与专属忍者模块处理战斗逻辑，`renderer.js` 与渲染模块绘制角色和特效。修改后将更新文件提交到同一仓库，Pages 会重新部署，网址保持不变。

本项目为非官方同人演示，数值和特效是自制实现。
